퇴직연금 장외채권 매수 모바일 신청 가이드 (미래에셋증권)

[목차]
퇴직연금 장외채권 매수 / 모의투자계산(만기상환) / 모의투자계산(중도매도) / 매수 취소

== 고객 확인사항 ==

1. 채권에 대한 전반적인 내용
- 채권 안내, 채권 유의사항을 참고하여 전반적인 내용 확인 후 매수를 신청해 주시기 바랍니다.

2. 매수 가능시간
- 채권 매수 가능시간은 10:00~15:00(영업일 기준)입니다. ※ 15:00 이후 매수·취소 불가

3. 모바일(M-STOCK) 매도 불가
- 모바일(M-STOCK)로 채권 매수·취소는 가능하지만, 매도는 불가합니다. ※ 매도 : 영업점 방문 or 유선 처리

4. 위험자산·집중 투자한도
- 국채 외에 채권(지방채·특수채·회사채)은 퇴직연금 감독규정 상 위험자산에 해당합니다. ※ 위험자산·집중 투자한도 동시 충족 필수
※ 중요 : "계열회사 등이 발행한 채권에 대한 매수한도"를 초과할 경우 매수신청이 취소될 수 있습니다.

5. 보유한 현금성자산
- 보유한 현금성자산으로 채권 매수가 가능합니다. ※ 교체매매를 통한 채권 매수 불가

== 준비사항 ==

1. M-STOCK을 설치해 주세요.
2. 퇴직연금(개인형IRP) 계좌 개설 : 퇴직연금(개인형IRP) 계좌가 없다면 M-STOCK에서 개설해 주세요.
※ DC·기업형IRP는 가입자명부 등록 후 자동 계좌 개설(연금관리 → DC계좌 온라인등록 메뉴에서 등록 후 가능)
3. 회원가입·인증 등록 : 회원가입 후 간편인증 등록 or 공동인증서를 발급해 주세요.

== 퇴직연금 장외채권 매수 신청 ==

1. 금융상품 매매 메뉴 : M-STOCK 투자하기 > 연금 > 금융상품 매매
2. 계좌 선택 : 퇴직연금(DC·기업형IRP/개인형IRP) 계좌 선택
3. 장외채권 탭 선택 : 채권명, 채권코드로 검색 가능. 수익률 높은순 정렬, 투자수익률(연)·잔존기간·위험자산한도 70%·투자한도 30% 등 표시
4. 매수할 채권 선택 : 채권의 투자등급(예: 저위험(4등급)), 신용등급(예: A0), 투자수익률(연), 잔존기간 확인
5. 유의사항 팝업 확인 : [회사채/특수채 투자 시 유의사항] 투자하신 채권들 중 서로 계열 관계인 채권들의 합계 금액이 고객님 적립금의 40%를 넘을 수 없습니다. (예시) A전자 채권 20% + A화학 채권 20% → 투자가능 / A전자 채권 30% + A화학 채권 20% → 투자불가. ※ 채권매수 신청 마감(15시) 이후 위 사항에 해당될 경우, 퇴직연금 관련 법규에 따라 매수취소 처리될 수 있음을 알려드립니다.
6. 발행정보 상세 확인 → 매수 버튼 클릭 : 기본정보(투자등급, 신용등급, 이자지급방법, 표면금리, 발행일자 등) 확인 후 매수 버튼 클릭
7. 매수수량 입력 : 매수수량은 1,000단위(천원)로 입력. 매수가능수량 계산기에서 매수희망금액(총액)을 입력하면 채권 최대 매수가능금액 확인 가능. ※ 매수수량 입력 전 디폴트옵션증거금 해지 가능. 화면에 채권 매수 최대가능수량과 채권 매수 최대가능금액이 표시됩니다.
8. 유의사항 문구 체크 → 다음 버튼 클릭 : 매수가능금액 = 가용현금(매수가능금액+디폴트옵션증거금). ※ 회사채/특수채 매수 시 체크 필수 : "근무하는 회사 또는 계열사 등이 발행한 채권이거나, 동일 계열 관계 채권 합계금액이 적립금의 40%가 넘을 경우 매수취소 처리될 수 있습니다."
9. 투자성향 확인 : 고객님의 투자성향(성장형/위험중립형/안정추구형/안정형 등)을 확인합니다. ※ 투자성향, 투자권유여부에 따라 추가 서류 확인 - 상품위험등급 > 투자성향 : 적합(적정)하지 않는 투자성상품 거래 확인서 / 투자권유여부-불원 : 투자권유 희망 및 투자자정보제공여부 확인서
10. 상품위험등급 확인 : 상품위험등급(초고위험 1 / 고위험 2 / 중위험 3 / 저위험 4 / 초저위험 5) 확인, 투자설명서·채권 설명서·운용지시 안내장 확인
11. 설명서 및 유의문구 확인 → 다음 버튼 클릭 : 투자설명서, 채권 설명서, 운용지시 안내장, 투자설명서 제공 및 설명 확인, 전자문서로 설명서를 받음에 동의, 만기 상품의 만기 처리 내용 확인(만기가 있는 상품(예금 등)의 경우 만기예정일의 직전 영업일 전까지 고객님의 별도 의사표시가 없을 경우 만기상환하여 현금성자산으로 운용됩니다. 단, 디폴트옵션을 지정하신 경우 디폴트옵션 절차에 따라 매수됩니다.)
12. 매수 정보 확인 → 매수 버튼 클릭 : 매수계좌, 매수금액, 매수수량(천원), 매수단가, 채권종류명, 이자지급유형 확인 후 매수
13. 매수 신청 완료 : "매수신청이 완료되었습니다." ※ 간편인증 or 공동인증 절차 진행. 신청 내역조회 가능

== 모의투자계산(만기상환) ==

1. 발행정보 상세 확인 → 모의투자계산 버튼 클릭
2. 매수수량, 매수일자 입력 → 다음 버튼 클릭 : [만기상환] 선택, 매수수량(액면) 입력(매수가능수량 계산기 활용하여 매수수량 입력 가능), 매수일자 입력
3. 모의투자내역 확인 : 매매구분(만기상환), 매수수량(천원), 매수일자, 매수금리, 매수단가, 상환일자, 투자등급, 신용등급 확인
4. 예상수익 확인 → 자세히 보기 버튼 클릭 : 발행이자율, 이자지급유형, 투자기간, 총투자수익률, 세후투자수익률(연), 예금환산수익률(세전,연), 매수금액(A), 상환금액, 실수령합계(B), 총과표, 원천징수금액, 실손익(B-A) 확인
5. 현금흐름상세 확인 : 지급일별 세전금액, 세금, 세후금액 상세내역 확인

== 모의투자계산(중도매도) ==

1. 발행정보 상세 확인 → 모의투자계산 버튼 클릭
2. 매수수량, 매수일자 입력 : [중도매도] 선택, 매수수량(액면) 입력, 매수일자 입력
3. 매도일자, 매도금리 입력 → 다음 버튼 클릭 : 물가상승률, 매도일자, 매도금리 입력
4. 모의투자내역 확인 : 매매구분(중도매매), 매수수량(천원), 매수일자, 매수금리, 매수단가, 상환일자(매도일자), 투자등급, 신용등급 확인
5. 예상수익 확인 : 발행이자율, 이자지급유형, 투자기간, 총투자수익률, 세후투자수익률(연), 예금환산수익률(세전,연), 매수금액(A), 상환금액, 실수령합계(B), 총과표, 원천징수금액, 실손익(B-A) 확인
6. 현금흐름(요약) 확인 → 자세히 보기 버튼 클릭
7. 현금흐름상세 확인 : 지급일별 세전금액, 세금, 세후금액 상세내역 확인

== 매수 취소 ==

1. 연금계좌현황 메뉴 : M-STOCK 투자하기 > 연금 > 연금계좌현황
2. 계좌 선택 : 퇴직연금(DC·기업형IRP/개인형IRP) 계좌 선택
3. 금융상품/디폴트옵션 → 신청/매매내역 : 신청중 탭에서 매수 매매접수 내역 확인
※ 매수취소 가능 시간 : 매수신청 당일 15:00까지
4. 매수취소 버튼 클릭
5. 매수신청취소 버튼 클릭 : 신청내역 상세에서 금액/비율, 주문일, 결제일 확인 후 매수신청취소. ※ 간편인증 or 공동인증 절차 진행
6. 운용지시취소 확인 : "매수취소 신청이 완료되었습니다."
